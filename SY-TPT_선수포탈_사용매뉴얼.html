SY-TPT · PLAYER USER GUIDE

매뉴얼의 목적과 화면 구성

SY-TPT 선수 포탈은 선수 계정으로 로그인해 코치가 배정한 미션을 확인하고, 경기 준비 체크리스트를 관리하고, 훈련 후 자기평가를 저장하고, 코치와 메시지를 주고받는 웹 앱입니다. 선수 포탈에서 연결되는 시합 기록·훈련 일정·퍼팅·리듬 훈련은 각각 별도 화면 또는 서비스로 열립니다.

이 매뉴얼의 범위: 로그인 직후 선수에게 표시되는 메인 화면과 그 안에서 선택할 수 있는 모든 탭·버튼·아이콘을 설명합니다. 코치 전용 선수 관리·미션 배정·체크리스트 편집 기능은 선수 화면에서 사용할 수 없습니다.
화면 영역선택 후 표시되는 화면 / 용도
상단 바현재 로그인 계정·역할을 표시합니다. 뒤로가기, 포탈 선택(역할 허용 시), 언어 변경, 로그아웃을 제공합니다.
현재 관련 선수 현황선수명, 미션 완료율, 경기력 수준, 계정 상태를 요약합니다. 별도의 상세 화면으로 이동하는 메뉴는 아닙니다.
시합준비현재 경기명과 기간, 경기 전·중·후 체크리스트, 일정·경기 기록 도구를 한곳에서 이용합니다.
Player Dashboard / Self Evaluation / Coach Communication선수 포탈 안에서 대시보드, 자기평가, 코치 메시지 화면을 전환합니다. 활성 탭을 다시 선택하면 해당 패널을 접습니다.
Mission Dashboard / Putting Training / Putting Evaluation / Rhythm_Tempo Training별도 훈련 서비스 또는 웹 화면을 엽니다. 현재 포탈의 내부 탭은 유지됩니다.

CHAPTER 01

로그인·가입과 상단 아이콘

기존 계정 로그인

  1. 로그인 탭에서 코치가 발급한 선수 ID와 비밀번호를 입력합니다.
  2. 로그인을 선택하고, 로그인 후 상단에 표시되는 이름과 역할이 본인 정보인지 확인합니다.
  3. 승인 대기 메시지가 표시되면 로그인 화면으로 돌아가거나 코치에게 승인 상태를 문의합니다.

선수 가입 신청

  1. 선수 가입 탭을 선택합니다.
  2. 선수 이름, 사용할 선수 ID, 비밀번호(화면 안내 기준 8자 이상)를 입력합니다.
  3. 선수 가입 완료를 선택하고 승인 대기 안내를 확인합니다.
아이콘 / 선택 항목선택하면 보이는 화면과 사용법
뒤로가기 (시작 화면)가입 또는 승인 대기 패널에서 로그인 패널로 돌아갑니다. 시작 화면 밖으로 임의 이동하는 대신 앱의 안내된 화면을 전환합니다.
뒤로가기 (로그인 후)내부 탭이 열려 있으면 Player Dashboard로 돌아갑니다. 코치 계정은 코치 포탈에서 Player 포탈로 돌아갑니다.
🏌 PlayerPlayer Portal을 표시합니다. 선수 로그인 시 기본 포탈이며, 코치 계정은 선수 화면 보기로 전환할 때 사용할 수 있습니다.
🎯 Coach코치 계정에만 표시되는 포탈 선택입니다. 선수 계정에는 표시되지 않습니다.
언어 선택한국어/English를 선택하면 포탈 UI 언어가 바뀝니다. 체크리스트 항목에 저장된 언어와 설명은 항목 설정에 따라 다르게 보일 수 있습니다.
로그아웃현재 인증 세션을 종료하고 로그인 화면으로 돌아갑니다. 공용 기기에서는 사용 후 로그아웃하세요.
계정 보호: 비밀번호를 다른 사람과 공유하지 마세요. 선수 ID·비밀번호 분실, 승인 대기 또는 계정 비활성화는 코치에게 문의합니다.

CHAPTER 02

메인 화면 모든 선택 아이콘

아래 표는 선수 로그인 후 메인 화면에서 직접 선택할 수 있는 버튼·아이콘을 모았습니다. 날짜 버튼과 경기명은 눌러 편집하고, 단계 체크박스는 수행 상태를 기록합니다.

아이콘 / 버튼선택 후 표시되는 화면사용 순서
경기명경기명을 편집하는 입력 UI가 열립니다.현재 대회 이름을 확인하고 수정한 뒤 저장합니다. 새 시합 일정으로 바꾸면 이전 체크 항목은 새 일정에 맞게 초기화될 수 있습니다.
기간 표시 / 📅 달력 아이콘경기 날짜 선택 창이 열리고 시작일·종료일 입력란, 취소·저장 버튼이 보입니다.시작일과 종료일을 모두 선택하고 저장합니다. 종료일은 시작일보다 빠를 수 없습니다. 취소 또는 Esc를 누르면 저장하지 않고 닫습니다.
🗓 훈련 스케줄훈련 일정 관리 화면을 새 탭으로 엽니다.저장된 훈련 일정에서 항목을 선택해 기간, 장소, 시간대, 세부 훈련 내용을 확인합니다. 선수 화면은 조회 전용이며 파일 내보내기는 필요할 때 사용할 수 있습니다.
📈 샷거리시뮬레이터샷 궤적·거리 계산 도구를 새 탭으로 엽니다.투어 기준 또는 개인 입력을 선택하고 클럽·출발 조건·환경을 확인한 뒤 실행합니다. 바람, 라이, 시점 보기 등은 각 설정 영역에서 바꾸고 결과는 모의 추정치로 해석합니다.
오늘경기데이터 입력골프 라운드 간편 기록 화면을 새 탭으로 열고 현재 세션을 전달합니다.선수·날짜·코스 정보와 단위를 확인하고 라운드를 시작합니다. 홀마다 샷 종류를 선택해 결과를 기록·저장하고 이전/다음 홀로 이동합니다.
지난경기조회할 경기 이력을 번호로 고르는 창을 표시하고, 선택한 경기의 히스토리를 Dashboard에 엽니다.목록의 번호를 입력합니다. 기록이 없으면 안내가 표시됩니다. 히스토리 패널의 닫기를 선택하면 현재 대시보드로 돌아갑니다.
Pre-Match / In-Match / Post-Match 체크박스선택한 항목의 완료 표시가 켜지거나 꺼지고, 저장 상태 문구가 보입니다.경기 전·중·후 단계별로 실제 수행한 항목만 체크합니다. 완료한 항목은 취소선으로 표시됩니다. 항목 설명의 ▼/▲를 선택하면 설명을 펼치거나 접습니다.
Player Dashboard오늘 날짜·미션 수, 수행 미션, 완료 미션, 코치 알림과 지난경기 패널을 보여줍니다.오늘 할 미션을 확인하고 제목을 선택해 상세를 엽니다.
Self Evaluation집중도·심리상태·체력상태·특이사항 입력과 최근 7일 이력이 있는 화면을 엽니다.하루 훈련 후 값을 선택·기록하고 자기 인지 데이터를 저장합니다.
Coach Communication코치 지시/대화 목록, 질문 작성·첨부, 답변 상태 화면을 엽니다.전달사항을 읽고 필요한 질문을 작성한 뒤 첨부를 선택하고 전송합니다.
Mission Dashboard ↗외부 Mission Dashboard를 새 탭으로 엽니다.열린 미션 서비스에서 화면 안내를 따릅니다. 포탈 탭 화면 자체는 이동하지 않습니다.
Putting Training ↗Putting Training 서비스를 새 탭으로 엽니다.열린 서비스의 훈련 화면에서 안내대로 연습합니다.
Putting Evaluation ↗Putting Evaluation 사이트를 새 탭으로 엽니다.평가 사이트로 이동해 제공되는 평가 절차를 따릅니다.
Rhythm_Tempo Training리듬·템포 훈련 앱을 실행합니다.열리는 훈련 화면의 샘플·재생 컨트롤을 이용해 리듬을 연습합니다.
저장 상태를 꼭 확인: 단계 항목을 체크하면 서버에 저장됩니다. “저장되었습니다.”는 서버 저장 완료, 서버 저장 실패 안내는 다른 기기에 반영되지 않을 수 있음을 뜻합니다. 실패하면 네트워크를 확인하고 다시 접속해 상태를 확인하거나 코치에게 알리세요.

CHAPTER 03

Player Dashboard와 미션 화면

화면 / 선택 항목선택하면 표시되는 화면사용 순서
오늘 날짜 / 오늘 미션 수현재 날짜와 오늘의 미션 수를 상단 요약 카드에 표시합니다.정보 요약이므로 선택 입력은 없습니다. 미션 수는 오늘 수행할 항목과 오늘 새로 배정된 완료 항목을 기준으로 계산됩니다.
미션 제목 버튼선택한 미션의 코치 피드백, 첨부파일, 수행 상태와 종료 버튼을 상세 영역에 펼칩니다.미션 코드를 눌러 상세를 확인합니다. 첨부 파일 이름을 선택하면 파일을 엽니다/다운로드합니다.
✅ 미션 종료미션의 수행 상태를 완료로 변경합니다.지시된 수행을 마친 뒤 선택합니다. 실제 입력 상태가 바뀐 것을 확인하고, 잘못 완료한 경우 완료 미션 목록에서 “완료 취소 (재개)”를 사용합니다.
완료 미션 보기 / 접기완료된 미션 카드와 상세 패널을 아래에 펼치거나 접습니다.완료한 미션 제목을 눌러 피드백·결과 첨부를 확인합니다. 다시 수행해야 하면 상세의 “완료 취소 (재개)”를 선택합니다.
코치 메시지 알림새 코치 지시·메시지가 있음을 알리는 요약을 표시합니다.메시지 내용은 Coach Communication 탭을 열어 읽습니다.
지난경기 패널 닫기현재 열려 있는 과거 경기 기록 패널을 닫습니다.닫기 후 오늘 미션과 코치 메시지가 있는 기본 Dashboard로 돌아옵니다.
  1. 오늘 날짜와 상단의 선수 이름을 확인합니다.
  2. 오늘 수행할 미션에서 제목을 눌러 상세 지시와 첨부 결과 파일을 확인합니다.
  3. 미션을 수행한 뒤 미션 종료를 선택하고, 완료 상태를 확인합니다.
  4. 이전 완료 기록은 완료 미션 보기에서 확인합니다. 재수행이 필요할 때만 완료 취소를 선택합니다.
미션 종료는 수행 상태를 변경합니다. 미션을 시작하거나 수행 내용을 제출하는 별도 양식으로 오인하지 말고, 코치가 요청한 절차를 먼저 완료한 후 사용하세요.

CHAPTER 04

Self Evaluation 입력·저장 화면

입력 항목 / 버튼화면 동작과 사용법
오늘 집중도1~5 중 하나를 선택합니다. 오늘 훈련 후 본인의 실제 집중 정도를 기록합니다.
심리상태복수 체크 항목에서 해당하는 감정·상태를 선택합니다. 선택한 값은 입력란 아래에 요약 표시됩니다.
체력상태복수 체크 항목에서 현재 신체 컨디션을 선택합니다. 체크 결과가 입력란 아래에 표시됩니다.
오늘훈련특이사항오늘 훈련에서 기억해야 할 내용을 글로 입력합니다. 필요한 범위에서 구체적으로 기록합니다.
자기 인지 데이터 저장선택한 집중도, 심리·체력 상태, 메모를 오늘 날짜 기록으로 저장합니다. 완료 안내를 확인한 뒤 최근 7일 이력을 확인합니다.
최근 7일 저장이력최근 날짜순으로 일자, 집중도, 심리·체력 상태와 특이사항을 보여줍니다. 이 영역은 조회용 표입니다.
  1. 훈련을 마친 뒤 Self Evaluation 탭을 선택합니다.
  2. 집중도를 선택하고 심리·체력 상태를 해당하는 만큼 체크합니다.
  3. 특이사항을 입력하고 자기 인지 데이터 저장을 누릅니다.
  4. 저장 완료 안내가 표시되면 최근 7일 이력에서 기록을 확인합니다. 같은 날짜에 다시 저장하면 해당 일자 기록이 갱신됩니다.
저장된 자기평가는 이후 PDI 분석에 활용됩니다. 상태를 과장하거나 추측하기보다 실제 훈련 후 본인이 느낀 내용을 기록하세요.

CHAPTER 05

Coach Communication 화면

화면 / 선택 항목선택하면 표시되는 내용사용 순서
코치 지시사항 열람코치가 보낸 지시와 대화 메시지를 시간순으로 표시합니다. 메시지 첨부파일은 다운로드 링크로 보입니다.먼저 코치의 요청을 읽고 필요한 파일 링크를 선택해 확인합니다.
코치에게 질문 / 답변 요청질문을 작성하는 텍스트 입력란을 제공합니다.질문 또는 수행 관련 문의를 입력합니다. 빈 메시지는 전송되지 않습니다.
첨부 파일 선택기기 파일 선택기가 열립니다.PDF, Word, Excel, PNG 파일을 선택합니다. 각 파일은 5MB 이하로 첨부합니다.
전송질문과 선택한 첨부파일을 코치에게 보냅니다. 대화와 답변 상태가 갱신됩니다.수신인에게 전달할 내용을 확인한 뒤 한 번 선택합니다. 전송 오류 안내가 나오면 네트워크와 파일 형식·크기를 확인하고 다시 시도합니다.
답변 상태코치 메시지 수, 선수 질문 수, 답변 대기 수를 요약합니다.답변 대기 숫자가 남아 있으면 대화 목록을 확인하고, 새 답변이 보이지 않으면 화면을 다시 열거나 새로고침합니다.
미확인 메시지 배지Coach Communication 탭에 읽지 않은 메시지 수가 표시될 수 있습니다.탭을 열어 코치 지시와 답변을 확인합니다.
파일 업로드 중 오류가 표시되면 지원 형식과 파일당 5MB 제한을 확인하세요. 오류가 계속되면 첨부 없이 메시지를 보내고 코치에게 파일을 전달할 다른 방법을 문의합니다.

CHAPTER 06

연결 도구가 여는 화면과 문제 해결

훈련 스케줄 · 일정 조회 화면

시합준비 제목 옆의 훈련 스케줄 달력 아이콘을 선택하면 별도 탭에 저장된 훈련 일정 목록이 열립니다. 일정을 선택해 메인 훈련 제목, 기간, 장소, 날짜별 시간대와 세부 훈련 내용을 확인합니다. 선수에게는 조회 권한만 표시되며, 엑셀 업로드·일정 추가·편집·저장·초기화는 코치 전용입니다. CSV/엑셀 내보내기는 현재 표시된 일정 데이터를 파일로 저장합니다.

샷거리시뮬레이터 화면

샷거리시뮬레이터는 선수 포탈에서 새 탭으로 여는 별도 도구입니다. 투어 기준 또는 개인 입력을 선택하고, 클럽과 볼 출발 조건을 확인한 뒤 환경 설정을 조절해 샷을 실행합니다. 측면/위에서 보기, 실행·리셋을 이용해 궤적을 살펴봅니다. 개인 기준 샷과 바람·라이 보정 등은 모델 기반 추정이므로 실제 샷의 보장값으로 사용하지 마세요. 개인 입력은 현재 브라우저 도메인에 저장되며 다른 기기·도메인 또는 선수 계정으로 자동 동기화되지 않습니다.

오늘경기데이터 입력 화면

  1. 선수 이름, 라운드 날짜, 코스명, 코스 전장, 코스 파와 거리 단위를 확인합니다.
  2. 라운드 시작을 눌러 홀 기록 화면으로 이동합니다. 현재 홀, 총 샷 수와 완료 홀 수가 표시됩니다.
  3. 홀의 Par·거리를 확인하고 필요하면 거리 단위 변환 버튼(⇄)을 사용합니다.
  4. 샷 종류 탭에서 티샷, 세컨/서드, 어프로치, 퍼팅 또는 레이업을 선택해 해당 입력 양식을 작성한 뒤 저장/수정을 누릅니다.
  5. 이전/다음으로 홀을 이동해 기록을 이어갑니다. 잘못된 샷은 해당 기록을 수정하고, 진행 중에는 메인으로 돌아가기 전에 저장 상태를 확인합니다.

문제 해결

증상확인 방법
로그인할 수 없거나 승인 대기 표시선수 ID를 확인하고 승인 여부를 코치에게 문의합니다. 승인 전에는 로그인할 수 없습니다.
체크리스트가 다른 기기에 반영되지 않음체크 직후 저장 상태 메시지를 확인합니다. 서버 저장 실패 안내가 있으면 네트워크 연결을 확인하고 재시도합니다.
지난경기 목록이 비어 있음등록·보관된 경기 기록이 없을 수 있습니다. 현재 시합 기간을 확인하고 코치에게 확인합니다.
코치 메시지나 첨부가 보이지 않음Coach Communication 화면을 다시 열고 연결 상태를 확인합니다. 파일당 5MB 및 지원 형식을 확인합니다.
외부 도구가 열리지 않음새 탭이 차단되지 않았는지 브라우저 설정을 확인합니다. 도구의 입력 데이터는 서비스별로 저장되며 포탈에 자동 전송된다고 가정하지 마세요.
개인정보·기록 보호: 공용 기기에서 로그아웃하고, 경기나 자기평가 입력 후 저장 완료 여부를 확인하세요. 시합 날짜를 새 일정으로 바꾸기 전에 체크리스트 초기화 안내를 주의 깊게 읽으세요.

About This Manual and the Screen

SY-TPT Player Portal lets players sign in to review coach-assigned missions, manage match-preparation checklists, save post-practice self-evaluations, and exchange messages with a coach. Round entry, training schedules, putting, and rhythm practice open as separate pages or services.

Scope: This manual covers every selectable player-facing tab, button, and icon on the home screen and explains the screen shown after selection. Coach-only athlete management, mission assignment, and checklist editing are not available in a player account.
AreaScreen shown / purpose
HeaderShows the signed-in account and role. Provides Back, role-permitted portal selection, language, and Log out.
Current Player SummarySummarizes player name, mission completion, performance level, and account status. It is not a separate navigation menu.
Match PreparationGroups the current match name/dates, Pre/In/Post-Match checklists, schedule, and round tools.
Player Dashboard / Self Evaluation / Coach CommunicationSwitches between the dashboard, self-evaluation, and coach-message panels within the portal. Selecting the active tab again collapses its panel.
Mission Dashboard / Putting Training / Putting Evaluation / Rhythm_Tempo TrainingOpens a separate training service or page; the portal tab itself remains in place.

CHAPTER 01

Sign-in, Registration, and Header Controls

Existing account

  1. Select Log in, enter the player ID and password issued by the coach, and select Log in.
  2. Confirm that the signed-in name and role in the header are yours.
  3. If approval is pending, return to the login panel or ask the coach about the approval status.

Player signup

  1. Select Player signup.
  2. Enter the player name, a player ID, and a password of at least eight characters as requested on screen.
  3. Select Complete signup and wait for coach approval.

CHAPTER 06

Linked Tools and Troubleshooting

Training Schedule · read-only schedule view

Select the Training Schedule calendar icon beside Match Preparation to open saved training schedules in a separate tab. Select a schedule to review its title, date range, location, time slots, and daily training details. Player access is read-only; Excel upload, adding/editing schedules, saving, and reset controls are coach-only. CSV/Excel Export downloads the currently displayed schedule data.

Shot Distance Simulator

The Shot Distance Simulator opens in a new tab from the player portal. Select tour baseline or personal data, confirm the club and launch conditions, adjust environmental settings, and run the shot. Use side/top views and reset to inspect the trajectory. The model provides estimates, not guaranteed real-shot results. Personal inputs are stored for the current browser origin and are not automatically synchronized across devices, domains, or player accounts.

Enter Today’s Round Data

  1. Confirm player, round date, course, course length, par, and distance unit.
  2. Select Start Round to open the hole-record screen, which shows the current hole, total shots, and completed holes.
  3. Confirm each hole’s par and distance; use the unit-conversion (⇄) control if needed.
  4. Select Tee Shot, Second/Third, Approach, Putt, or Layup, complete the corresponding fields, and save/update the shot.
  5. Move between holes with Previous/Next and verify records before returning to the portal.

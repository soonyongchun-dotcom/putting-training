# 샘플 배경음악

이 폴더에 WAV 파일을 추가하면 앱에서 배경음악으로 사용할 수 있습니다.

추가할 파일 이름 예시:
- `파도소리1.wav`
- `파도소리2.wav`
- `파도,갈매기1.wav`
- `빗소리1.wav`
- `봄비소리.wav`
- `바람1.wav`
- `바람3.wav`
- `물받는소리.wav`
- `물끓는소리.wav`
- `모닥불.wav`
- `도랑물2.wav`
- `도랑물.wav`
- `새소리.wav`

현재 이 프로젝트는 `backgroundMusic`에서 `없음`과 `사용자 WAV 업로드`만 지원하도록 설정되어 있으므로,
`사용자 WAV 업로드`를 선택하고 로컬 WAV 또는 MP3 파일을 업로드해 사용하세요.

원한다면 이 폴더에 샘플 파일을 생성하는 스크립트도 제공합니다:
- `generate_nature_samples.js`

이 스크립트는 명령줄에서 `node generate_nature_samples.js`로 실행하면 위 파일 이름들로 샘플 WAV 파일을 생성합니다.

# 골프 리듬 & 템포 모바일 트레이너

모바일에서 재생 가능한 리듬 음원을 생성하는 간단한 웹 앱입니다.

## 기능

- 드라이버, 아이언, 숏게임, 퍼팅별 리듬 패턴
- 템포(BPM) 및 스윙 속도 조절
- 선수 유형별 맞춤 프로필
- 모바일 브라우저에서 즉시 재생 가능

## 사용 방법

1. `index.html`을 모바일 브라우저에서 엽니다.
2. 샷 유형을 선택합니다.
3. 템포와 스윙 속도를 조절합니다.
4. `재생` 버튼을 눌러 리듬을 듣습니다.

## 확장 아이디어

- 선수별 리듬 저장 및 불러오기
- 집중 사운드 선택 옵션 추가
- 사용자 WAV/MP3 업로드 배경음악 지원
- 클럽별 세팅 저장 및 즉시 불러오기 기능 추가
- `generate_nature_samples.js`로 자연 사운드 샘플 WAV 파일 생성 가능
- 한 손/양 손 터치 전용 모바일 UI 개선
- MIDI 또는 WAV 파일 생성
